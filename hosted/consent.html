采集范围、用途与保存方式

只用于改进游戏和人机协作的评估方法，不公开原始数据。游戏没有玩家聊天输入框，记录的是局面、操作和模型的动作选择。

会保存

  • 游戏引擎事件
  • 初始局面、每秒状态变化与关键事件状态
  • 结算结果与报告的 token 用量（非账单）
  • 物品、订单、工位、动作与决策关联
  • 实际地图、菜谱、规则、种子与版本
  • 记忆开关与使用局数
  • 全部操作输入：移动、位置、转向、按键和投掷，可原样重放整局
  • 双方开始操作的时刻，以及投掷是否瞄准队友
  • 每次给 Jeff 的请求的校验值，以及重建请求所需的最近决策和预设沟通消息（含发送时间）
  • 模型给出的各选项概率（如有）
  • 开启跨局记忆时，用到了哪几局（局号）及记忆内容的校验值
  • 本局模型服务与模型 ID（含自定义模型，注明浏览器上报、未经独立核验）

不会保存

  • API Key
  • IP 与账号身份
  • 模型接口地址
  • 跨局记忆的内容（只记局号和校验值）

不另存完整 API 请求或响应。每次请求只保存校验值和重建它所需的少量内容，研究时用操作记录把原请求重建出来。开启跨局记忆时记下的局号，能把这个浏览器里的几局联系起来。

自动贡献会在开局时创建私有记录；正常结束、手动结束、重开、关闭请求或闲置回收时更新。突然断电或进程崩溃可能只保留未完成的开局记录，不会推断退出原因。记录容量耗尽会明确标注丢失范围。

对局记录统一保存在腾讯云中国上海；海外站经加密连接提交和访问记录。

私有保存，半年（180 天）后自动删除。每份贡献的删除凭证保存在这个浏览器里，可随时在「设置 → 数据与贡献」提前删除或更改选择。

选择“暂不”时，也可以在结算画面点「贡献本局」只贡献这一局。没有开局前同意时，只含已有事实与首尾状态，不含操作记录，缺失过程会标注。
