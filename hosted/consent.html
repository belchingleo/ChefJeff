采集范围、用途与保存方式

只用于改进游戏和人机协作的评估方法，不公开原始数据。游戏没有玩家聊天输入框，记录的是局面、操作和模型的动作选择。

会保存

  • 游戏引擎事件
  • 初始局面、每秒状态变化与关键事件状态
  • 结算结果与报告的 token 用量（非账单）
  • 物品、订单、工位、动作与决策关联
  • 实际地图、菜谱、规则、种子与版本
  • 记忆开关与使用局数
  • 本局模型服务与模型 ID（含自定义模型，注明浏览器上报、未经独立核验）

不会保存

  • API Key
  • IP 与账号身份
  • 模型接口地址
  • 跨局记忆内容与预设沟通

模型请求和返回按游戏状态、候选动作、选项与执行结果等结构化字段保存，不另存完整 API 请求或响应。

自动贡献会在开局时创建私有记录；正常结束、手动结束、重开、关闭请求或闲置回收时更新。突然断电或进程崩溃可能只保留未完成的开局记录，不会推断退出原因。记录容量耗尽会明确标注丢失范围。

私有保存 30 天后自动删除。每份贡献的删除凭证保存在这个浏览器里，可随时在「设置 → 数据导出」提前删除或更改选择。

选择“暂不”时，也可以在结算画面点「贡献本局」只贡献这一局。没有开局前同意时，只含已有事实与首尾状态，缺失过程会标注。
