· 隐私说明 ↗

自愿参与。只有选「同意贡献」才会保存；选「暂不」也能正常游玩，随时可以在「设置 → 数据与贡献」更改。

用途：改进游戏，研究人机协作的评估方法，并建立开放的人机协作基准。原始记录不公开。游戏没有玩家聊天输入框，记录的是局面、操作和模型的动作选择。

会保存

  • 游戏引擎事件
  • 初始局面、每秒状态变化与关键事件状态
  • 结算结果与报告的 token 用量（非账单）
  • 物品、订单、工位、动作与决策关联
  • 实际地图、菜谱、规则、种子与版本
  • 玩自制关卡时：这张关卡的完整设计，包括你起的关卡名和菜名
  • 记忆开关与使用局数
  • 全部操作输入：移动、位置、转向、按键和投掷，可原样重放整局
  • 双方开始操作的时刻，以及投掷是否瞄准队友
  • 每次给 Jeff 的请求的校验值，以及重建请求所需的最近决策和预设沟通消息（含发送时间）
  • 模型给出的各选项概率（如有）
  • 开启跨局记忆时，用到了哪几局（局号）及记忆内容的校验值
  • 本局模型服务与模型 ID（含自定义模型，注明浏览器上报、未经独立核验）

不会保存

  • API Key
  • IP 与账号身份
  • 模型接口地址
  • 跨局记忆的内容（只记局号和校验值）

不另存完整 API 请求或响应。每次请求只保存校验值和重建它所需的少量内容，研究时用操作记录把原请求重建出来。开启跨局记忆时记下的局号，能把这个浏览器里的几局联系起来。

保存：私有保存在腾讯云（中国上海），海外站经加密连接提交。研究者会把记录下载到自己的电脑上分析。原始记录（包括下载的副本）最长保存两年，研究项目提前结束时一并删除，不做备份。

公开数据集：相关研究发表后，我们可能把记录整理成数据集公开发布，任何人都可以下载使用，具体许可在发布时注明。发布前会对数据做脱敏处理，除了对局本身，只保留模型服务和模型 ID。

删除：每局的删除凭证保存在这个浏览器里，可以在「设置 → 数据与贡献」删除。每份公开数据集只收录发布日 30 天以前贡献的对局，所以每局贡献后，你至少有 30 天可以删除；被收进数据集以后，就认不出是哪一局了，无法再删除。

自动贡献会在开局时创建私有记录；正常结束、手动结束、重开、关闭请求或闲置回收时更新，提前结束的对局也包括在内。突然断电或进程崩溃可能只保留未完成的开局记录，不会推断退出原因。记录容量耗尽会明确标注丢失范围。关闭自动贡献会撤回本局未结束的记录。

选「暂不」时，也可以在结算画面点「贡献本局」只贡献这一局。没有开局前同意时，只含已有事实与首尾状态，不含操作记录，缺失过程会标注。
