免费模型

列表由服务器提供，新接入的免费模型会直接出现在这里。

免费模型的使用限制

  • 每个免费模型同一时间只能一位玩家使用，国内站和海外站共用这个名额。
  • 名额满了不排队：可以稍后再试，或者换另一个免费模型。
  • 不想等名额，可以自己去智谱、Bamboo 等平台申请免费的 API Key，填在“自定义模型”里使用。这样不占这里的名额，限额按你在服务商那边的账号算。
  • 每局最多向模型请求 200 次，没成功的请求也算在内。
  • 全站每小时、每天的免费请求总数也有上限。某个模型今天的额度用完后，会显示“今日额度已用完”，第二天恢复。
  • 开局时固定本局的模型，结算后才能换。
